## Instructions for Elementor Deployment

1. Download each Unsplash asset listed above.
2. Convert images to modern `.webp` format using your preferred image compressor (e.g. Squoosh or Photoshop).
3. Upload files to **WordPress → Media Library**.
4. In Elementor container/widget settings, replace placeholder URLs with native Media Library images.
